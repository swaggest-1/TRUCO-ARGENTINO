# truco-argentino
un juego hecho con claude de truco argentino, juga contra un bot y con o contra tus amigos
# como instalar
simplemente instala index.html, automaticamente abrira una partida contra un bot
# como jugar con tus amigos
en la esquina superior derecha esta el boton "Jugar con un amigo", este hara aparecer un panel, si vos queres crear la sala, toca "crear sala" y pasale el codigo a tu amigo, el cual lo debe poner en donde dice "C O D I G O" y presionar "unirme"
